使用说明

  • 全盘播放：选好范围（本节 / 本大类 / 全书）与顺序，点 ▶ 即可连续朗读。默认「意→中（逐条）」= 单词意语 → 中文释义 → 下一个单词。
  • 点读：点击任意意语单词或中文释义可单独发音；例句的意语句与中文翻译也可分别点读。
  • 拼音与音标：每条中文带拼音、每条意语带IPA 音标；点右上角「拼」可整体隐藏/显示，方便自测。
  • 快捷键：空格 播放/暂停，← → 上一条/下一条，/ 聚焦搜索。
  • 进度：右上角「学完」可标记小节，状态存本地浏览器。
  • 站内按「大篇 → 大类 → 小节」三级结构组织（8 大篇 / 47 大类 / 389 小节）。各小节内容当前为空，待你在 data/sec/<gid>.js 对应小节填入 终极分类词(w) / 经典实用句(s) / 词汇大拓展(e) 后，即可正常学习、播放与测验。
